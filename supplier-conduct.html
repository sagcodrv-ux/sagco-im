ISO 20400 / / L3-SCoC-001 Rev.01 — The SAGCO Supplier Code of Conduct defines minimum ESG standards for all Tier-1 and critical Tier-2 suppliers. Non-signature within 30 days triggers Tier 2 escalation per L2-IMS-1000-P-07 §8. This page tracks sign-off status. The full SCoC text is in L3-SCoC-001 Rev.01 (IMS Documentation Register Sheet 17).
