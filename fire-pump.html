L4-SHEE-PR-14-ML-01 · ISO 45001 §8.1 / NFPA 25 practice — Fire Pump Test Log, covering the Diesel Firefighting Pump (HSE-FRM-11) and Electrical Firefighting Pump (HSE-FRM-12) inspections, each at two cadences: a Daily/weekly visual check and a Monthly No-Flow ("Churn") Test run. Every log sheet below reproduces the item set and column layout of its corresponding paper form exactly, so the printed version can stand in for the original.
⚠ The Electrical — Daily scenario is constructed from HSE-FRM-12's weekly visual-inspection items, laid out in the same Day 1–7 grid as the Diesel Daily form — no scanned Electrical Daily form was supplied for this build. Please verify this item set and layout against the actual field form before relying on it. The Diesel Daily grid also carries two item rows (#14 and #16) whose criteria text duplicates an earlier row verbatim, exactly as printed on the source PDF — flagging this in case it's a form typo rather than intentional. Two further requirements named on the previous placeholder page for this doc code are not yet modeled in this log-sheet register and would need separate handling if still required: an annual full-flow test by a Civil Defense-licensed engineer, and a <30-second pump-startup CRITICAL alert threshold.
